Website Clone Project
📌 About This Project
This project is a frontend clone of an existing website, recreated for learning and practice purposes. The goal was to understand real-world UI design, layout structure, responsiveness, and modern frontend development techniques.

🚀 Live Demo
🔗 https https://reimagining-cynthias-awarded-websit.vercel.app/

🛠️ Tech Stack Used
HTML
CSS
JavaScript
GSAP
Locomotive

✨ Features
Fully responsive design across devices
Smooth UI interactions and animations
Clean and structured component-based code
Fast loading and optimized layout
Pixel‑perfect recreation of the original design

🎯 What I Learned
Understanding real-world website layouts
Improving CSS positioning and responsiveness
Working with animations and interactive UI
Writing cleaner and more maintainable frontend code
